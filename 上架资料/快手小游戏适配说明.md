# 快手小游戏平台适配说明

> 项目:美食餐厅爱消消(Cocos Creator 3.8.8)
> 本文档记录快手小游戏平台的接入方式、构建流程与注意事项。

---

## 一、适配原理(重要)

Cocos Creator 3.8.x **没有独立的"快手小游戏"构建入口**。官方适配方式为:

1. 在 Cocos Creator 中按 **微信小游戏** 构建;
2. 安装官方 **快手小游戏构建扩展**,构建时勾选 **"适配快手小游戏"**(仅将 spine 的 wasm 替换为 asm.js,解决快手 wasm 兼容问题);
3. 用 **快手小游戏开发者工具** 打开构建产物,开启 **"自动适配微信小游戏"**(工具会生成 `kwaiadapter.js`,内容为 `GameGlobal.wx = ks`,把微信 API 桥接到快手 `ks` 命名空间)。

**运行时特征(代码判断依据):**

| 特征 | 值 |
| --- | --- |
| `sys.platform` | 仍为 `WECHAT_GAME`(引擎按微信运行) |
| 平台全局对象 | `ks`(微信对象 `wx` 由开发者工具适配层模拟) |
| 官方环境判断 | `typeof KSGameGlobal !== 'undefined'` |

因此项目内所有快手判断统一走 `KsManager.isKuaishouEnv()`,广告等开放能力一律调用 `ks.*` 原生 API,**不要**依赖 `wx.*`。

---

## 二、环境准备(一次性)

### 1. 安装快手构建扩展

1. 下载官方扩展:`https://static.yximgs.com/udata/pkg/KS-GAME/minigame/kwai_minigame_build_extension-1.0.6.zip`
2. Cocos Creator 菜单 **扩展 → 扩展管理器 → 导入扩展**,选择上面的 zip(选择"全局"或"项目"安装均可)。
3. 安装后,微信小游戏构建面板底部会多出 **"适配快手小游戏"** 勾选项。

### 2. 安装快手小游戏开发者工具

在快手开放平台(https://game.kuaishou.com)下载,使用时:

- **设置 → 本地配置 → 勾选"自动适配微信小游戏"**(关键,否则 `wx` 不存在,游戏起不来)。

---

## 三、构建发布步骤

1. Creator 菜单 **项目 → 构建发布**;
2. 发布平台选择 **微信小游戏**;
3. 勾选 **"适配快手小游戏"**(由快手构建扩展提供);
4. 引擎设置中如遇到 spine wasm 报错,将 **原生代码打包模式** 设为 **AsmJS**(3.8.3+ 引擎已内置回退,勾选扩展后通常已自动处理);
5. 构建完成后,用快手开发者工具打开构建目录(如 `build/wechatgame`),真机预览/上传。

> 抖音包仍按原方式构建(发布平台 → 抖音小游戏),两条链路互不影响。

---

## 四、广告位配置(必须)

在 **`assets/script/ks/KsManager.ts`** 顶部填写快手广告位 ID(在快手开放平台 → 小游戏 → 流量主后台申请):

```ts
public videoId: string = "";         // 激励视频广告位 ID
public interstitialId: string = "";  // 插屏广告位 ID
public bannerId: string = "";        // Banner 广告位 ID
```

- 留空 = 不加载该广告,相关入口会提示"暂未开放"或静默跳过,不会报错;
- 三个广告位均需在快手后台提前创建并**审核通过**才能拉到广告。

### 开屏广告(仅快手)

**展示规则**(硬性,写在代码里):

1. 仅快手平台展示(`KsManager.isKuaishouEnv()` 守卫),微信/抖音不展示;
2. 仅**首次游玩满 3 天(含)的老用户**展示——首次游玩时间在 `DSStorageManager.init()` 时写入本地缓存(`First_Play_Time`),此后不再更新;
3. 每次冷启动最多展示一次(`KsManager` 实例级标记)。

**实现方式与平台限制(重要)**:

- 快手小游戏**没有独立开屏广告 API**(`ks.createSplashAd` 不存在,官方仅提供激励视频/插屏/Banner 三种),开屏位以**插屏广告**实现;
- 平台频控规定**冷启动 30 秒内不允许播放插屏**,因此开屏广告会在**启动约 31 秒后**展示(代码已内置延迟兜底),并非启动瞬间的全屏广告;
- 广告位:优先使用 `KsManager.splashId`(可填专用插屏广告位便于单独统计),留空则回退 `interstitialId`;
- 老用户首启即会调度;新用户(3 天内)进入首页时跳过,不再弹启动插屏(避免启动位双弹)。

> 注意:本次更新上线前已在玩的老玩家没有历史首次游玩时间,会被记为"更新日首次游玩",即更新后 3 天内不展示开屏广告(保守策略,避免误伤)。

### 广告能力对照

| 广告形式 | 微信 | 抖音 | 快手 |
| --- | --- | --- | --- |
| 激励视频 | ✅ | ✅ | ✅ `ks.createRewardedVideoAd` |
| 插屏 | ✅ | ✅ | ✅ `ks.createInterstitialAd` |
| Banner | ✅ | ✅ | ✅ `ks.createBannerAd` |
| 开屏(启动位) | — | — | ⚠️ 以插屏实现,见下方说明 |
| 原生模板/格子 | ✅ | — | ❌ 暂不支持(已做空实现,打日志) |
| 九宫格/更多游戏 | — | ✅ | ❌ 抖音专属,快手隐藏入口 |

## 五、代码结构

```
assets/script/
├── ks/
│   └── KsManager.ts      # 新增:快手平台 SDK(激励视频/插屏/Banner/开屏广告、震动、分享、登录),单例 KsMgr
├── wx/
│   ├── advertise.ts      # 改造:Ads 广告路由,快手环境委托 KsManager(含 showSplashAds 开屏入口)
│   └── wxManager.ts      # 改造:快手环境跳过微信登录/游戏圈;震动走 ks.vibrate*
├── rank/utils/GameUtils.ts # 改造:isWx 排除快手(无开放数据域,防止误调 wx 云数据)
├── framework/DSStorageManager.ts # 改造:新增 First_Play_Time 首次游玩时间(老用户判断依据)
├── game/homeView.ts      # 改造:首页启动位——快手走开屏广告,其他平台维持启动插屏
└── dy/DyManager.ts       # 抖音逻辑不变(内部按 sys.platform 守卫,快手自动跳过)
```

**调用方无需改动**:各界面仍通过 `Advertise.showVideoAds() / showBannerAds() / showInterstitialAds()` 等入口调用,由 `Ads` 按平台自动分发(测试模式 `isTest=true` 时所有平台直接模拟成功,方便联调)。

## 六、平台注意事项(踩坑记录)

1. **插屏 30 秒冷却**:快手下游戏运行 30 秒内展示插屏会报错(`-20037`)。`KsManager.showInterstitialAds()` 与开屏广告均已内置延迟到 31 秒的兜底;进入首页即调用是安全的(会自动延后)。
2. **激励视频无 `load()`**:快手 `RewardedVideoAd` 只有 `show()`,不能像微信那样 `show().catch(() => load().then(show))`,代码已按快手规范改为失败即提示。
3. **`wx` 是模拟出来的**:微信登录、隐私接口、游戏圈、云数据(排行榜)在快手均不适用,相关入口已全部拦截;排行榜好友榜在快手不展示(无开放数据域),本地关卡排行不受影响。
4. **登录**:快手允许未登录进入游戏,`KsManager.login()` 仅按需调用,启动流程不强制登录。
5. **分享**:`ks.shareAppMessage` 存在但**无回调**,是否支持已做存在性检测。
6. **广告测试**:测试机的快手号需加入开发者后台白名单(约 20 分钟生效),否则激励视频黑屏/插屏报错。
7. **字体**:不要使用 `fontFamily: "Tahoma"`(快手安卓会乱码),项目当前未使用。
8. **spine wasm**:必须用"适配快手小游戏"勾选后的产物,否则快手运行报 wasm 错误。

## 七、上线检查清单

- [ ] 快手构建扩展已安装,构建时勾选"适配快手小游戏"
- [ ] `KsManager.ts` 三个广告位 ID 已填写且后台审核通过(开屏广告位 `splashId` 可选,留空则用插屏位)
- [ ] 快手开发者工具已开启"自动适配微信小游戏"
- [ ] 真机测试:激励视频(领取体力/道具)、Banner(首页/设置)、插屏(结算后)
- [ ] 真机测试:开屏广告——新用户(3天内)不展示;老用户冷启动约 31 秒后展示一次,杀死进程重进不重复展示
- [ ] 真机测试:震动开关、排行榜入口无报错
- [ ] iOS + Android 双端真机验证(iOS 不支持插屏,开屏/插屏会静默失败,需确认无报错)
- [ ] 后台配置包体、类目、隐私协议后提交审核
