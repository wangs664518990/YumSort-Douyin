## 一、资质(硬门槛,先办这个)

### 1.1 版号 —— 唯一不确定项,必须先问清

TapTap 的《小游戏内容规范》写明:

> 游戏需具备国家新闻出版署批准的版号(ISBN),**无版号游戏不得含内购计费内容**。
> 需提供软件著作权登记证书(软著)、ICP 核准信息及独家授权链证明(如适用)。

本项目是**纯 IAA(广告变现)、无内购**。按字面理解:无版号仍可能上架,但**不能有任何付费点**(不能有充值、内购礼包、去广告付费)。

**动作**:提工单问一句"无内购的 IAA 单机游戏,APK 正式上线是否必须版号",拿到书面答复再投入。别猜。

### 1.2 软著

| 要求 | 本项目 |
| --- | --- |
| 软件著作权登记证书扫描件 | ✅ `上架资料/软著.png`(821×1106,1.6MB,符合 JPG/PNG ≤2M) |
| 软著主体 = 提交游戏的公司主体 | ⚠️ 核对证书上的著作权人是否与你注册的开发者主体一致 |

### 1.3 ICP 核准信息

- 国内上架需要,通常是域名备案/ICP 许可证信息。
- 若游戏无服务端、无自有域名,按后台提示填(部分情况填"无")。
- **动作**:后台对应字段在哪、要不要,以「商店 → 游戏资料 → 游戏资质」页面为准。

### 1.4 开发者主体

- 个人开发者可注册,**但** APK 正式上线通常要求企业主体(个人主体一般只能发测试)。这一条同样提工单确认。
- 主体信息需与 Dirichlet 广告签约主体一致,否则广告收益结算会卡住。

## 二、包体要求

### 2.1 出包

| 项 | 要求 | 本项目 |
| --- | --- | --- |
| 签名 | release 必须签名;后台要登记**包名 + 签名信息**,两者必须与出包完全一致 | ⚠️ 出包时确认 keystore,别用 debug 签名 |
| ABI | 建议只保留 `arm64-v8a` | ⚠️ `build.gradle` 里 `PROP_APP_ABI`,多 ABI 会让包体翻倍 |
| 体积 | 平台未公开明确上限,但体积直接影响下载转化 | 当前 `build/android/data` 16MB,单 ABI 出包预计 30–40MB,可接受 |
| targetSdk | 需满足 Google Play / 国内商店的当年要求 | 以 Cocos 构建配置为准 |
| 版本号 | versionCode 递增,versionName 与商店资料一致 | ❌ 现在是 `1` / `"1.0"`,要正式填 |

> 包名改动 = 新应用,老用户数据全丢。**出第一个正式包前把包名定死。**

### 2.2 包内合规(缺一样就打回)

- [ ] **防沉迷**:TapSDK 已接入,`TapConfig.CLIENT_ID` 已填,真机日志无 `[防沉迷] 告警:`
- [ ] **实名认证**:未实名账号真机验证被正确拦截
- [ ] **广告合规**:激励视频玩家主动触发;插屏间隔 ≥2 分钟
- [ ] **隐私政策**:游戏内可不放,但后台「商店资料」的隐私政策链接必填
- [ ] **健康游戏忠告**:启动页已有(`loadingView.prefab`),文案已改为"本游戏"
- [ ] **无诱导分享 / 无强制广告**:分享不带奖励
- [ ] 包内无测试开关:`TapAdConfig.isTest = false`、`TapConfig.DEBUG = false`

## 四、商店资料:素材

官方尺寸(逐条核对自 TapTap 物料要求):

| 素材 | 尺寸/格式 | 是否必需 | 现有文件 | 结论 |
| --- | --- | --- | --- | --- |
| 图标 | **512×512**,JPG/PNG,关键内容在安全区 | ✅ 必需 | `512.png`(512×512) | ✅ **直接可用** |
| 详情页顶部图 | **1920×1080**(16:9),JPG/PNG,关键内容在 1760×920 安全区 | ✅ 必需 | 无 | ❌ **要新做** |
| 推广图 | 1920×1080(16:9),JPG/PNG | 可选 | 无 | 有顶部图可先不传 |
| 截图 | 全部**同尺寸**,≥3 张,JPG/PNG;竖版推荐 9:16 | ✅ 必需 | `微信图片_*.png` 4 张(1206×2622 ≈ 9:19.6) | ⚠️ 比例不是 9:16,建议重截 1080×1920 |
| 视频 | MP4,≤1GB,≤60 秒(推荐 20 秒),1280×720 起 | 可选 | 无 | 可不做 |
| 视频封面 | 1256×706,JPG/PNG | 传视频才需要 | 无 | — |
| 授权书 | JPG/PNG,单张 ≤2M,≤10 张 | 涉及 IP 才需要 | 无 IP | 不需要 |

**截图拍摄清单**(照这个拍,一次过):
1. 首页/主界面(带关卡与体力)
2. 核心消除界面(棋盘上有连击特效)
3. 结算/星级界面
4. 道具或解锁界面

> 硬要求:不要用加载页、空白页、过场动画当截图;不要重复上传同一张;不要加宣传文字(除游戏名)。

## 五、提审流程与时间

1. 后台「**商店 → 游戏资料 → 商店资料**」上传 APK(也可走 API,`cloud.tapapis.cn/apk/v1/upload-params`,签名 `X-Tap-Sign`;
   上传后约 **3–5 分钟**才能在列表里看到,且**只保留近 7 天上传的包**)
2. 填文字 + 素材 + 隐私政策链接
3. 「游戏资质」上传软著 / 版号 / ICP → **资质审核与包体审核是两条线,都要过**
4. 提交版本审核 → 首次预计 **1–3 日**
5. **审核通过 ≠ 上线**:上线是独立动作,在「发布设置」里点「立即上线」或「定时上线」
   (首次定时必须设在当前时间 **6 小时之后**;资质不支持定时,要预留时间)
